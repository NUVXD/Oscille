Dependencies
--

| Libraries |
|-----------|
| SDL3      |
| SDL3_TTF  |

Forks for the original repositories of SDL3 & SDL3_TTF are implemented in this program as submodules with pre-built libraries.  

This was the simplest way I found to include the libraries in a way that allows easy replacement, but you're free to use your own builds.

You can find the original repositories [here](https://github.com/libsdl-org).
